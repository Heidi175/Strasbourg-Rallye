STRASSBURG-RALLYE – FERTIGE VERSION

DIESEN ORDNER VERÖFFENTLICHEN
==============================

1. Auf github.com ein kostenloses Konto erstellen oder anmelden.
2. Oben rechts auf das Pluszeichen klicken und „New repository“ wählen.
3. Repository-Name: strassburg-rallye
4. „Public“ auswählen.
5. „Create repository“ anklicken.
6. „uploading an existing file“ anklicken.
7. ALLE Dateien aus diesem Ordner in das Upload-Feld ziehen.
   Wichtig: Nicht den äußeren Ordner hochladen, sondern dessen Inhalt.
8. Unten „Commit changes“ anklicken.
9. Im Repository „Settings“ öffnen.
10. Links „Pages“ wählen.
11. Unter „Build and deployment“:
    Source: Deploy from a branch
    Branch: main
    Folder: / (root)
12. „Save“ anklicken.

Danach erscheint nach kurzer Zeit eine Adresse nach diesem Muster:
https://DEIN-NAME.github.io/strassburg-rallye/

DIESE ADRESSE IST DIE STARTADRESSE DER RALLYE.

QR-CODE
=======
Die veröffentlichte Adresse in Safari oder Chrome öffnen und daraus einen QR-Code
erstellen. Der QR-Code bleibt gleich, solange dieselbe GitHub-Pages-Adresse benutzt wird.

TEST VOR DEM VERSENDEN
======================
- QR-Code mit einem Smartphone scannen.
- Teamnamen eingeben.
- Kompakte oder komplette Route wählen.
- Eine Station öffnen.
- Navigation testen.
- Eine Station auslassen.
- Seite neu laden und prüfen, ob der Fortschritt erhalten bleibt.

DATENSCHUTZ
===========
Es gibt keine Cloud und keine Anmeldung.
Antworten, Fotos und Fortschritt bleiben lokal auf dem Smartphone.
Beim Löschen der Browserdaten werden auch die Rallye-Daten gelöscht.

SPÄTERE ÄNDERUNGEN
==================
Im GitHub-Repository die alten Dateien durch neue ersetzen.
Die Webadresse und der QR-Code bleiben unverändert.

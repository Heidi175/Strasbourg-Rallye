AKTUALISIERUNG V2 – DEUTSCH / FRANÇAIS

Diese Version zeigt beim ersten Öffnen eine deutliche Sprachwahl:
- Français
- Deutsch

Die gewählte Sprache wird auf dem jeweiligen Smartphone gespeichert.
Über den Sprachknopf oben rechts kann sie jederzeit geändert werden.

SO AKTUALISIEREN SIE DIE BEREITS VERÖFFENTLICHTE WEBSITE
1. Öffnen Sie Ihr GitHub-Repository „Strasbourg-Rallye“.
2. Löschen oder überschreiben Sie die bisherigen Dateien.
3. Laden Sie ALLE Dateien aus diesem Ordner hoch:
   index.html
   style.css
   app.js
   stations.json
   manifest.webmanifest
   sw.js
4. Klicken Sie auf „Commit changes“.
5. Warten Sie etwa 1–3 Minuten.
6. Öffnen Sie dieselbe Adresse:
   https://heidi175.github.io/Strasbourg-Rallye/

Der Link und der QR-Code bleiben unverändert.

WICHTIG BEIM TEST
Da die frühere Version einen Offline-Cache benutzt hat, kann ein Smartphone
zunächst noch die alte Fassung anzeigen. Dann:
- Seite vollständig neu laden oder Browser-Tab schließen und neu öffnen.
- Falls nötig Browserdaten für die Seite löschen.
- Alternativ einmal in einem privaten Browserfenster testen.
